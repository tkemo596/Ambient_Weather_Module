Ambient Weather Driver

Adds an Ambient Weather device type to Ignition's OPC UA server. Each device polls the Ambient Weather REST API (GET /v1/devices) and exposes every station on the account, with one tag per reported field.

Setup

  1. On your AmbientWeather.net account page, create an Application Key and an API Key.
  2. In the gateway, go to Connections → Devices → Create Device and choose Ambient Weather.
  3. Enter both keys. Leave the base URL at its default; a 60-second poll interval is typical.
  4. Browse the device in the OPC browser: one folder per station, plus _Diagnostics.

Quality

  • Good – fresh reading.
  • Uncertain – the station's latest reading is older than Stale After.
  • Bad – the API call failed, a sensor dropped out, or a station was removed. The last value is kept.

Values carry the station's reading time as their timestamp. Units are as Ambient Weather reports them (°F, mph, inHg, in); each tag's description names its unit.
